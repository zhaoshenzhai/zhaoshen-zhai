# Working on the website

This is a static public site; [README.md](README.md) describes its layout. Keep personal administrative files and private mathematical sources out of it. PDFs under `data/` are published assets and belong in Git.

Preserve the `research`, `talk`, and `exposition` record types used by `js/data.js`. Check JSON syntax and changed local links. For visible changes, serve the repository over HTTP and verify the affected page, navigation, abstracts, and mathematics in a browser. Prose-only changes need a link and diff check.

Do not change deployment settings during unrelated work.
