# Working on the website

Read [README.md](README.md) and the affected HTML, JSON, JavaScript, or CSS before editing. This is a static public site. Keep personal administrative files and private mathematical sources out of it. PDFs under `data/` are published assets and belong in Git.

Preserve the `research`, `talk`, and `exposition` record types used by `js/data.js`. Check JSON syntax and changed local links. For visible changes, serve the repository over HTTP and verify the affected page, navigation, abstracts, and mathematics in a browser. Prose-only changes need a link and diff check.

Use a non-default branch and open or update a pull request. Merging and publishing require explicit approval. Do not change deployment settings during unrelated work. Keep README and this file about current use and boundaries; Git records history.
